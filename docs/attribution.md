# 作者与依赖

作者：郑皓文（Owen）。项目内容包括压力采样与标定接口、滤波与控制算法、运行模式、参数管理和界面集成。

## 软件组成

ESP-IDF 提供芯片支持、FreeRTOS、ADC、I2C 和 NVS 接口；LVGL 负责界面组件与渲染；触摸组件及显示移植代码来自仓库内保留署名的相关依赖。界面资源由 SquareLine 工程生成并通过应用桥接层与控制状态连接。

主程序与部分移植文件保留 Espressif / Waveshare 等来源说明，`components/` 中的第三方文件沿用各自许可。项目许可见 [LICENSE](../LICENSE)，具体文件的署名与条件同时保留。
