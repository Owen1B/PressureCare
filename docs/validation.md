# 台架验证与实现核对

## 现有证据

仓库保留[硬件照片](images/demo.jpg)、[主界面](images/ui1.png)、[设置界面](images/ui2.png)与[演示视频](https://github.com/user-attachments/assets/2721eb9b-3225-47eb-ae20-bf3e925fd7e3)。这些材料用于展示原型形态与交互，精度和动态性能需要关联独立测量记录。

当前文档依据源码整理，固件构建、控制回路和实机性能均需在配套环境中验证。涉及人体或临床用途的安全与有效性评估属于独立流程，本项目限于台架研究。

## 优先核对的实现问题

| 问题 | 源码依据 | 核对方式 |
| --- | --- | --- |
| 反馈方向 | PID 采用负压目标减当前压力，输出范围为非负，泵计数再取反。 | 先隔离动力，核查正负误差与实际泵作用方向；对照 `architecture.md` 的初始状态算例。 |
| 启动输出 | `app_main` 自动启动系统，UI 初始化包含 PWM 测试调用。 | 在接入负载前测量整个启动序列与停止电平。 |
| 压力量化 | HAL 输出整数 kPa，滤波结果也存入整数运行字段。 | 对照参考压力记录量化误差和控制量变化。 |
| 采样失败 | 控制任务调用 `hal_pressure_sensor_read` 后直接使用局部读数，返回值处理待完善。 | 注入读失败，定义本轮输出、状态和停止策略。 |
| PID 参数边界 | 积分限幅使用 `output_max / Ki`。 | 验证零值/异常增益、长间隔、启动与模式切换。 |
| 报警与模式 | 持续阈值检查在 UI 路径执行，自动停止默认关闭；休息阶段也需核对条件。 | 记录调用时刻，覆盖界面繁忙、休息周期和选项切换。 |
| 构建一致性 | 控制源文件和部分 UI 接口与当前构建清单有对齐项。 | 清洁构建、链接检查，保留软件和硬件配置。 |

这些项目是静态审阅发现的风险与验证要求；应以复现实验确定影响，再提交对应修复。

## 建议实验

| 实验 | 条件 | 记录内容 |
| --- | --- | --- |
| 传感器标定 | 独立参考仪器、多个压力点、重复采样 | 零点、比例系数、残差和重复性。 |
| 闭环阶跃 | 固定气路与容积、多个台架设定值 | 上升/下降时间、超调、稳态误差、PWM。 |
| 干扰响应 | 台架控制的泄漏或负载变化 | 恢复时间、饱和时长、积分状态。 |
| 工作周期 | 连续与间歇模式、边界时长 | 模式计时、重置行为、休息阶段压力。 |
| 故障处理 | 传感器/I2C 失败、异常压力、UI 忙碌 | 检测时间、停止输出与状态保持。 |
| 持续运行 | 固定输入及反复开关/切换 | 任务资源、运行周期分布与状态一致性。 |

每组记录至少包含芯片与板卡、固件提交、SDK、传感器标定、气路条件、`Q/R`、PID 增益和采样时间戳。原始读数、滤波值、目标和控制量应使用统一时间基准。

## 性能口径

控制任务在每轮结束后延时 100 ms，实际周期受采样、I2C、锁等待和 UI 回调耗时影响。频率或实时性指标应根据时间戳统计，而读数分辨率与测量精度分别报告。

精度采用独立参考压力对照；闭环稳定性与异常检测能力在指定气路、参数和故障集合下评估。文档中的公式和初始参数用于解释代码行为。
