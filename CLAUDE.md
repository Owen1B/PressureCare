## Project Overview

This is an **ESP32-S3 NPWT (Negative Pressure Wound Therapy) Device** project based on ESP-IDF framework with advanced LVGL GUI integration. The project implements a complete medical device control system with sophisticated display capabilities and precise hardware control.

## Build System and Common Commands

### Build and Flash
```bash
source ~/esp/esp-idf/export.sh

# Set target (required first time)
idf.py set-target esp32s3

# Configure project
idf.py menuconfig

# Build the project
idf.py build

# Flash and monitor
idf.py -p PORT flash monitor

# Clean build
idf.py fullclean
```

### Configuration
- Use `idf.py menuconfig` to configure project settings
- Navigate to "Example Configuration" → "Display" for LVGL/LCD settings
- Key configurations are also in `sdkconfig.defaults`
- NPWT-specific settings in `main/npwt_core.h`

## Project Architecture

This is a **4-layer architecture** medical device system:

### Layer 1: Application Layer - NPWT Core System
**Files**: `main/npwt_core.c/h`, `main/npwt_ui_bridge.c`

- **NPWT Control Logic**: Negative pressure therapy device implementation
- **Pressure Control**: -100kPa to 0kPa range, default -16kPa (-120mmHg)
- **Three Working Modes**:
  - Continuous mode: Constant negative pressure
  - Intermittent mode: Work/rest cycles  
  - Dynamic mode: Variable pressure patterns
- **PID Control Algorithm**: Precise pressure regulation
- **Kalman Filter**: Sensor data filtering for stability
- **Safety Systems**: Seal quality monitoring, leakage detection, alarm handling

### Layer 2: UI Layer - SquareLine Studio Interface
**Files**: `components/squareline_ui/`, `main/npwt_ui_events.c`

- **Professional Medical UI**: Generated by SquareLine Studio
- **Real-time Data Display**: Pressure, flow rate, seal quality indicators
- **Touch Control**: Parameter adjustment, mode selection, power control
- **Multi-language Support**: Chinese fonts and localization
- **Custom Events**: UI-to-core system communication bridge

### Layer 3: LVGL Port Layer - Display Framework
**Files**: `main/lvgl_port.c/h`

- **Advanced LVGL Integration**: Complete LVGL 8.x porting
- **Anti-tearing Technology**: 3 modes for smooth rendering
  - Mode 1: LCD double-buffer & LVGL full-refresh
  - Mode 2: LCD triple-buffer & LVGL full-refresh  
  - Mode 3: LCD double-buffer & LVGL direct-mode (recommended)
- **Screen Rotation**: 0°/90°/180°/270° support with pixel rotation algorithms
- **Multi-buffer Management**: 2-3 frame buffers for tear-free display
- **Thread-safe Operations**: Mutex protection for LVGL API calls
- **Task Management**: Dedicated LVGL timer task on CPU core 1

### Layer 4: Hardware Abstraction Layer
**Files**: `main/waveshare_rgb_lcd_port.c/h`

- **RGB LCD Driver**: 800x480 ST7701 controller support
- **Touch Controller**: GT911 I2C capacitive touch
- **I2C Bus Management**: Shared bus for touch and PCA9685
- **PWM Control**: PCA9685 12-bit PWM for pump control
- **GPIO Configuration**: Complete pin mapping for ESP32-S3

## Hardware Configuration

### Core Hardware
- **MCU**: ESP32-S3 dual-core @ 240MHz
- **Memory**: 8MB Flash + PSRAM (OCT mode, 120MHz)
- **Display**: 4.3" 800x480 RGB LCD (ST7701)
- **Touch**: GT911 I2C capacitive touch controller
- **PWM Controller**: PCA9685 (I2C address 0x40)

## NPWT System Specifications

### Pressure Control
```c
#define NPWT_PRESSURE_MIN        -30     // kPa (updated range)
#define NPWT_PRESSURE_MAX        0       // kPa  
#define NPWT_PRESSURE_DEFAULT    -16     // kPa (~-120mmHg)
```

### PWM Control
```c
#define NPWT_PWM_STARTUP         1638    // 40% startup duty cycle (60% pump speed)
#define NPWT_PWM_WORKING_MAX     1638    // 40% max duty cycle (60% pump speed)
#define NPWT_PWM_WORKING_MIN     0       // 0% min duty cycle (100% pump speed)
```

**PID Control Range (Reverse Logic)**:
- PID output: 0-1638 maps to 40%-0% duty cycle (60%-100% pump speed)
- Higher PID output = Lower duty cycle = Higher pump speed
- Formula: `pwm_duty = 1638 - pid_output`

### Safety Features

**Anomaly Detection with 60-second Initialization Delay**:
- **Leakage Detection**: Pressure -3 to 0kPa for 5 seconds (when target < -5kPa)
- **Blockage Detection**: Pressure < -32kPa for 5 seconds  
- **Initialization Period**: 60 seconds after power-on before anomaly detection starts
- **Status Display with Countdown**: 
  - During initialization: "初始化中（XX秒）" showing remaining time
  - After 60 seconds: "正常运行"
  - Power off during init: Returns to "准备就绪"
  - Power on again: Restarts full 60-second initialization

**Seal Quality Monitoring**: 0-100% quality indication based on flow analysis
- Excellent (100%): Leakage < 1.0 L/min
- Good (80%): Leakage < 3.0 L/min  
- Fair (60%): Leakage < 6.0 L/min
- Poor (40%): Leakage < 10.0 L/min
- Very Poor (20%): Leakage ≥ 10.0 L/min
